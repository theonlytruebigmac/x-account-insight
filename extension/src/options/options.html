Community Cloud Cache

Self-hosted, off by default. This talks to a server run for a specific community, not a third party — you need an API key from whoever runs it for you. While on, this account's lookups share the same subset of public profile facts with that server: the country and device X reports, affiliation badge, creation date, numeric account ID, and handle-change count. All of it is already public on the account's own profile. Nothing about you is sent beyond that.
